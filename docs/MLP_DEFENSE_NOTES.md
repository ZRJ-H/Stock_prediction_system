# MLP 模型答辩说明

> 用途：帮助答辩成员解释贵州茅台历史盲测使用的 MLP 模型、训练方法、实验结果和能力边界。

## 1. 一句话说明

本项目使用 sklearn 的多层感知机（MLP）作为贵州茅台日线涨跌二分类模型：

> 输入目标日前 60 个交易日的开盘、最高、最低、收盘和成交量，输出目标交易日上涨或下跌的概率。

模型只针对：

```text
600519 贵州茅台
```

不能直接用于其他股票。

## 2. MLP 是什么

MLP 全称 Multi-Layer Perceptron，即多层感知机，是一种前馈神经网络。

它由三类层组成：

- 输入层：接收历史行情特征。
- 隐藏层：通过权重、偏置和激活函数学习非线性关系。
- 输出层：输出上涨和下跌两个类别的概率。

当前模型结构为：

```text
输入 60 × 5 = 300 个特征
  -> 隐藏层 128 个神经元
  -> 隐藏层 64 个神经元
  -> 二分类输出
```

隐藏层使用 ReLU 激活函数，训练优化由 sklearn `MLPClassifier` 完成。

## 3. 输入如何构造

每个训练样本使用连续 60 个交易日，每日包含：

```text
open, high, low, close, vol
```

因此原始窗口形状是：

```text
(60, 5)
```

MLP 不直接处理二维时间序列，所以训练时展开为：

```text
60 × 5 = 300维向量
```

目标日的数据不会进入输入窗口。例如预测 2025-01-02：

```text
输入：2025-01-02 之前的60个交易日
标签：2025-01-02 相对前一交易日上涨还是下跌
```

这保证模型在预测时没有提前看到答案。

## 4. 数据与标签

数据来源：

- 股票：贵州茅台 `600519`
- 来源：AKShare 调用东方财富历史行情
- 周期：日线
- 复权：前复权 `qfq`
- 快照范围：`2015-01-05 ~ 2026-06-08`
- 有效数据：2775个交易日

标签定义：

```text
目标日收盘价 > 前一交易日收盘价 -> 上涨
否则                              -> 下跌
```

模型只预测方向，不预测具体价格和收益率。

## 5. 数据预处理

五个特征的数值范围不同，例如价格与成交量不能直接比较，因此使用 Min-Max 归一化：

```text
(x - 训练集最小值) / (训练集最大值 - 训练集最小值)
```

重要约束：

- Scaler 只在训练集拟合。
- 验证集和测试集使用同一组训练参数转换。
- 测试区间的最高价、最低价不会提前参与归一化参数计算。

这用于避免未来信息泄漏。

## 6. 时间序列切分

数据按时间先后切分，不能随机打乱：

```text
前70%：训练集
中15%：验证集
后15%：测试集
```

实际区间：

| 数据集 | 日期范围 | 用途 |
|--------|----------|------|
| 训练集 | 2015-04-07 ~ 2023-01-19 | 学习模型参数 |
| 验证集 | 2023-01-20 ~ 2024-09-25 | 检查泛化表现 |
| 测试集 | 2024-09-26 ~ 2026-06-08 | 最终评估和历史盲测 |

历史盲测只能从测试集抽取目标日期。

## 7. 实际训练结果

| 指标 | 结果 |
|------|------|
| 样本数量 | 2715 |
| 训练准确率 | 78.26% |
| 验证准确率 | 54.55% |
| 测试准确率 | 47.79% |
| 多数类基线 | 44.85% |

结果解释：

- 训练准确率明显高于验证和测试准确率，说明模型存在过拟合。
- 测试准确率只有47.79%，不能证明模型具备稳定预测能力。
- 它略高于当前测试报告中的多数类基线，但仍不足以支持真实交易。
- 项目保留真实结果，是为了展示模型审计，而不是美化准确率。

## 8. 为什么选择 MLP

选择 MLP 的原因：

- 比传统线性模型能表达更复杂的非线性关系。
- 训练速度快，当前数据几秒即可完成。
- 模型文件小，约 763 KB。
- 不依赖 TensorFlow，答辩机器更容易部署。
- sklearn 接口稳定，便于保存、加载和测试。

局限：

- 展平输入后，时间位置被当作固定特征，缺少循环或注意力结构。
- 参数较多，容易对有限样本过拟合。
- 只使用 OHLCV，不包含公司基本面、新闻、政策和市场情绪。
- 股价方向本身噪声很强，模型准确率不必然高于简单基线。

## 9. MLP 与 CNN、LSTM 的区别

| 模型 | 特点 | 本项目取舍 |
|------|------|------------|
| MLP | 展平输入，结构简单，部署轻量 | 当前盲测实际使用 |
| CNN | 用卷积提取局部时间模式 | 项目保留实现，但答辩模型未使用 |
| LSTM | 通过循环结构建模长期依赖 | 当前未实现 |

答辩时必须准确表述：

> 当前历史盲测实际使用的是 sklearn MLP，不是 CNN，也不是 LSTM。

## 10. 置信度如何理解

模型输出：

```text
上涨概率、下跌概率、置信度
```

置信度取两个类别概率中的较大值，但它只表示模型内部的相对倾向，不代表经过严格概率校准的真实成功率。

例如“上涨，置信度70%”不能解释为：

> 这只股票有70%的真实概率上涨。

更准确的说法是：

> 在当前模型参数下，上涨类别的输出得分高于下跌类别。

## 12. 答辩常见问答

**问：为什么选择 MLP？**

> MLP 能学习非线性关系，同时训练快、模型小、不依赖重型深度学习环境，适合课程项目和离线答辩。我们也承认它对时序结构的表达能力有限。

**问：为什么输入是60天？**

> 60个交易日大约对应三个月行情，既能提供短中期趋势信息，又不会让输入维度过大。窗口大小固定后，每个样本有300个特征。

**问：为什么测试准确率不到50%？**

> 股票短期方向噪声很高，同时训练集和测试集市场分布不同。结果说明模型存在过拟合和泛化不足。项目的创新点是通过隔离测试集和历史盲测把这个问题真实展示出来。

**问：训练准确率为什么那么高？**

> 模型在训练数据上学习得较充分，但没有同等程度地适应未来数据，这是典型过拟合。训练准确率高不等于预测能力强。

**问：模型能用来炒股吗？**

> 不能。测试准确率、交易成本、风险控制和跨时间稳定性都不足以支持实盘。模型只用于课程中的时间序列分类和模型审计实验。

**问：为什么不能预测其他股票？**

> 模型只用贵州茅台数据训练，不同股票的价格分布、波动和交易行为不同。直接跨标的推理缺乏统计依据，因此系统主动拒绝。

## 13. 一句话总结

> 本项目使用轻量 MLP 对贵州茅台60日日线窗口做涨跌二分类，并通过时间隔离、训练报告和历史盲测公开展示其过拟合与泛化边界。
